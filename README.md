## Blinkit Sales Analysis 
📌 Project Overview

This project analyzes Blinkit’s sales performance using Python, Pandas, and Plotly.
The goal is to understand customer purchasing patterns, store performance, and key factors affecting sales across different outlets and product categories.

The analysis explores:

Outlet-wise sales performance

Impact of product features (fat content, item type, visibility, MRP)

Customer buying behavior

Comparison between store tiers

Sales trends & business insights

This project is created as part of my Data Analyst learning journey, focusing on data cleaning, visualization, and storytelling.

🔍 Key Analysis Performed
1️⃣ Outlet Location Performance

Compared sales across Tier 1, Tier 2, and Tier 3 stores to identify:

Highest-performing tier

Customer purchase behavior by location

Which outlet tier contributes most to revenue

2️⃣ Item Type Sales Analysis

Analyzed sales across 16+ product categories:

Fruits & Vegetables

Snack Foods

Household Goods

Dairy, Meat, Soft Drinks etc.

Visualized which item type generates the highest and lowest revenue.

3️⃣ Impact of Item Fat Content

Studied how Low Fat and Regular items perform in different locations:

Comparison within each tier

Overall contribution to sales

Customer preference patterns

4️⃣ Item MRP vs Sales

Checked how product price (MRP) influences:

Sales volume

Revenue

Demand patterns

5️⃣ Item Visibility Analysis

Evaluated how product visibility affects sales performance.
